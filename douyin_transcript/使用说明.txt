==============================
  抖音文字稿提取工具 · 使用说明
==============================

【这是什么】
把抖音视频的口播内容提取成文字稿（TXT 文本，可选 SRT 字幕）。
全程在本机完成，不上传、不需要注册、不需要 API Key。

【怎么用 · 三步】
1. 在抖音 App 或网页里，把视频的分享链接复制下来
   （App 里点"分享 → 复制链接"；网页里直接复制地址栏）。
2. 双击 douyin_transcript.exe（不用输入任何东西，它会自动读剪贴板）。
3. 等待处理，完成后会自动用记事本打开文字稿；
   文件保存在本目录的 output 文件夹里。

   也可以在命令行里直接传链接：
     douyin_transcript.exe https://v.douyin.com/xxxxxx/

【需要多久】
- 视频自带字幕：几秒钟出结果。
- 无字幕视频：需要下载视频并用 AI 转写，
  耗时约为视频时长的一半到一倍（5 分钟视频约 2~5 分钟，取决于电脑性能）。

【文件放哪了】
- 文字稿：output\ 目录（每次一个 TXT，文件名即视频标题；分段版每段带 [分:秒-分:秒] 时间标记）
- 视频缓存：cache\ 目录只是临时中转，转写成功即自动删除，不留视频文件

【常用选项（命令行）】
  --srt          同时输出带时间轴的 SRT 字幕文件
  --with-meta    文字稿开头附上视频标题、作者、链接
  --model base   换用更小更快的模型（更省时但错字略多）
  --no-open      完成后不自动打开文件
  --segment      转写后调用 AI 按话题分段、加小标题（原文不改一个字）
  --classify     转写后自动按内容领域分类归档（见下）
  --notion       把文字稿存进自己的 Notion 笔记（需先配置，见下）

【自动分段（可选，需已配置 .env.local 的 MiniMax 密钥）】
运行时加 --segment，转写完成后 AI 会把整篇文字稿按话题重新分段，
并在话题切换处加上 ## 小标题。程序会逐字校验 AI 的输出与原文一致，
不一致就自动重试，重试到底也不通过就保留原稿——原文不会被改动。
已生成的旧文稿也能补分段：
  python segment_transcript.py            （全部，已处理的自动跳过）
  python segment_transcript.py --dry-run  （只看结果不写回）

【自动分类归档（可选，需已配置 .env.local 的 MiniMax 密钥）】
运行时加 --classify，视频转写完成后会调用 MiniMax 判断内容领域
（AI与技术 / 财经商业 / 自媒体与个人成长 / 教育与职场 / 社会时事 /
生活娱乐 / 其他），并把文稿移到 output\<类别>\ 子文件夹里。
也可以对已生成的文稿批量补分类：
  python classify_transcript.py            （全部）
  python classify_transcript.py --dry-run  （只看结果不移动）

【存进 Notion 笔记（可选）】
1. 打开 https://www.notion.so/my-integrations 新建一个集成，复制 Secret。
2. 在你要存放笔记的 Notion 页面右上角 … → 连接 → 添加这个集成。
3. 在本文件夹里新建 .env.local，写入两行：
     NOTION_TOKEN=粘贴你的 Secret
     NOTION_PARENT=粘贴那个页面的链接
4. 运行时加 --notion 参数，文字稿就会作为子页面存进该页面。
   （.env.local 只放在你自己电脑上，不要发给别人）

【常见问题】
- 提示"剪贴板为空"：先复制链接，再双击运行。
- 提示被风控/获取失败：抖音偶发限流，等一两分钟重试即可。
- 杀毒软件报毒：本工具未签名，个别杀软会误报，添加信任即可。
- 图集（多图）内容没有语音，无法提取。
- 请把整个 douyin_transcript 文件夹放在一起，不要单独移动 exe。

【环境要求】
Windows 10/11 64 位。如双击报缺少 DLL，请安装
微软 VC++ 运行库（https://aka.ms/vs/17/release/vc_redist.x64.exe）。
